# ByteSize Entertainment website prototype

A responsive cinematic front-end concept for ByteSizeEnt.com, featuring equal FILMAKA and FILMAIKA pathways.

## Features
- Persistent search input in the top navigation with live title suggestions (does not jump down the page).
- Catalog with collection filters, genre filters, sorting, detail views and local saved titles.
- Dedicated vertical Reels section with All / FILMAKA / FILMAIKA filters and reel preview overlays. The previews use poster imagery; real video playback requires licensed video files.
- Sign-in demo profile stored locally in the browser. This is not secure production authentication.
- Upgrade plans modal with Starter, Plus and Studio demo selections. No real payment is processed. Connect a payment provider and server-side subscription verification before taking payments.
- Responsive desktop and mobile layouts.

## Run locally
Open `index.html` in a modern browser. Some visual poster backgrounds load from Unsplash and need an internet connection.

## Before production
Connect a real database and catalog API, secure authentication, licensed film/reel assets, payment processing, server-side authorization, privacy/terms pages, and hosting/domain configuration. Sample catalog content is illustrative, not the actual Filmaka library.
